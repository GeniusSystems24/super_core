# super_core example

Example application for the `super_core` design-system package.

Run from this folder:

```bash
flutter run
```

Screens:

- Theme demo with palette and theme-mode controls.
- Widget gallery using `SuperSectionCard`, `SuperSectionHeader`, tiles, app bars,
  snack bars, sliders, buttons, and spacing-driven surfaces.
- Layout components screen demonstrating `SuperScaffold`, `SuperBreakpoint`,
  `SuperBreakpointProvider`, `SuperGrid`, `SuperGridCell`, and
  `SuperGridScope`.
- Section components screen demonstrating `SuperSectionCard`,
  `SuperSectionHeader`, `SuperSectionFooter`, `SuperFooterLink`, `Hairline`,
  generated headers, custom headers, footers, selected states, and expansion.
- Compact create-account form using the latest section-card and spacing APIs.
- Dialog/View examples for `SuperConfirmView`, `SuperConfirmDialog`,
  `SuperFieldView`, and `SuperFieldDialog`, including modal results,
  destructive confirmation, and the themed action-footer surface.
- Arabic / RTL examples across the gallery, layout, section, theme, and form
  screens.
